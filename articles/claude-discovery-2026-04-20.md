## 通勤電車でiOSアプリを作り、9分で審査を通過した話

スマホしか持っていない状態で、2週間後にはApp Storeにアプリが並んでいた。Zennに投稿された@ruwatana氏の開発記録は、「Claude Code on the Web」の可能性を端的に示している。

開発したのは「Cartera」という資産ポートフォリオ管理アプリ。日本株・米国株・投資信託・暗号資産をまとめて管理でき、任意のWebサイトからXPathで価格を取得する機能まで備えている。技術スタックはReact Native + Expo。注目すべきは開発スタイルで、通勤電車や休憩時間にスマホからClaudeアプリで指示を出し、クラウド上のClaude Codeが自動でコーディング。PRを確認してマージするだけという「ながら作業」で完成させた。App Store審査は9分で承認。設計段階でガイドラインへの抵触を事前検討していたことが効いたという。

PCを開く時間がない人でも、アイデアさえあればアプリを出せる時代が本当に来た。広告やマーケ領域のプロトタイプ検証にも応用できそうだ。

## GMOが実践する「8エージェント×21スキル」の開発オーケストレーション

GMOインターネットグループの研究開発本部が、Claude Codeの基本機能だけでどこまで自動化できるかを検証した結果を公開している。外部フレームワークを最小限に抑えた「軽量アプローチ」という点が興味深い。

彼らが構築したのは、8種類のエージェント定義と21種類のスキル定義、4つのカスタムHookからなる自動化基盤。その成果として、プロフィール画面8つの実装を約30分で完了させた。従来なら半日以上かかる作業だ。さらに「経験則自動メモリ」という仕組みで、ユーザー指示から修正パターンを検出しKnowledge化することで、同じミスの繰り返しを防いでいる。ドキュメントの自動メンテナンスにより、トークンコストも3〜10分の1に削減した。

小規模チームでも実装可能な構成で、「Claude Codeをどう設計すればスケールするか」の実践的な参考になる。

## 「寝ている間にバグ修正」を可能にするClaude Routines

4月14日、Anthropicが「Claude Code Routines」のリサーチプレビューを公開した。これは「PCを閉じても動き続けるClaude Code」を実現するクラウドベースの自動化機能だ。

Routineとは、保存されたClaude Code設定のこと。プロンプト、リポジトリ、接続ツール（GitHub、Slack、Linearなど）を定義しておけば、スケジュール・APIコール・GitHubイベントをトリガーに自律実行される。たとえば「毎晩2時にLinearから最優先バグを取得し、修正を試みてドラフトPRを作成」といった運用が、人間が寝ている間に進む。

これまでのClaude Codeは「自分がPCの前にいるときだけ動く」という制約があった。Routinesはその壁を取り払い、CI/CDパイプラインの一部としてAIを組み込む道を開いた。クライアントワークで「夜のうちに下書きを作っておく」といった使い方も視野に入る。

[Medium - Anthropic Just Launched Claude Routines](https://medium.com/the-ai-studio/anthropic-just-launched-claude-routines-6430dd721e4a)

## PRレビューを4人のAIエージェントが分担する「Claude Code Review」

3月にローンチされたClaude Code Reviewは、Anthropic社内でも使われている「エージェントチームによるコードレビュー」の実用例だ。

仕組みはシンプルで、PRが作成されると複数のエージェントが並列でコードを検査する。Correctness Agentがロジックとエッジケースを検証し、Security Agentが脆弱性をスキャン、Performance Agentが非効率を指摘し、Style & Consistency Agentがコーディング規約への準拠をチェックする。変更のサイズと複雑性に応じてエージェント数を調整し、1000行以上の変更では84%のPRで問題を検出、平均7.5個の指摘を行った。

Anthropic社内での実績では、「実質的なレビューコメント」が16%から54%に増加したという。人間のレビュアーを置き換えるのではなく補完する設計で、自動承認はしない。「レビュー待ち」のボトルネック解消に使えそうだ。

[InfoQ - Anthropic Introduces Agent-Based Code Review for Claude Code](https://www.infoq.com/news/2026/04/claude-code-review/)

## 非エンジニアの経理担当者が請求書処理を87%高速化した話

Claude Codeは開発者だけのツールではない。Uravationの記事では、非エンジニアによる業務自動化の具体的な数字が公開されている。

もっとも劇的だったのは経理部門の事例。フォルダ内のPDFファイルを読み込んで請求書情報をExcelにまとめる作業が、4.5時間から35分に短縮された（87%削減）。営業部門ではCSVの月別集計が3時間から14分へ（93%削減）。カスタマーサポートでは顧客メールの返信下書き生成が15分から3分へ（80%削減）。

記事では「ExcelマクロやGASに変わる、新しい自動化技術」としてClaude Codeを位置づけている。プログラミング知識ゼロでも、やりたいことをチャットで伝えるだけで自動化の仕組みが作れる。広告運用のレポート作成や、クライアントへの定型報告にも適用できるパターンだ。

[Uravation - Claude Codeで非エンジニアが業務を自動化する方法10選](https://uravation.com/media/claude-code-business-automation/)

## /batchコマンド：数千のエージェントを並列に走らせる

Claude Code作成者のBoris Cherny氏が公開した「隠れた便利機能15選」の中で、もっともインパクトがあるのが/batchコマンドだ。

これは数百から数千の独立したエージェントに変更を分散実行させる機能。従来は数日かかる大規模リファクタリングを数時間に圧縮できる可能性がある。同記事では/loopや/scheduleといった自動化機能も紹介されており、「人間が寝ている間もStale PRの整理やフィードバック収集が回り続ける」運用が可能になっている。

地味だが便利なのは/btw（サイドクエリ）。実行中のタスクを中断せずにちょっとした質問を投げられるコマンドで、作業フローを切らずに済む。「想像以上に快適」という評価には納得感がある。

[Qiita - Claude Code作成者が明かす、隠れた便利機能15選](https://qiita.com/dai_chi/items/df0c48ea6a3dc67e9e58)
